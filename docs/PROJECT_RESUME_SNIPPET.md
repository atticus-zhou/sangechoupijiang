# 三个臭皮匠项目介绍（简历版）

## 三个臭皮匠｜多 Agent 协作工作台

项目背景：

- 在市场调研、AI 漫剧制片、内容策划等复杂任务中，单一大模型往往只能给出一次性文本回答，难以持续完成“需求澄清、任务拆解、素材生成、质量审核、文档交付”的完整工作流。
- 为探索 AI 产品从“聊天工具”走向“可交付工作台”的形态，独立设计并开发了一个本地优先的多 Agent 协作平台，将复杂任务拆分到不同“办公室”和部门 Agent 中协同处理。

项目任务：

- 从 0-1 规划产品架构，设计“办公室大厅 + 二级办公室工作台”的产品结构，并确立办公室之间代码隔离、模型配置隔离、产物隔离和历史隔离的底层原则。
- 设计并实现“研究办公室”和“AI 漫剧制片办公室”两个核心场景：前者面向市场调研、竞品分析、截图证据和报告交付；后者面向剧本共创、人物/道具/场景资产拆解、导演提示词生成和 Word 制片画布导出。
- 将“三省六部”抽象为多 Agent 协作流程：中书省负责需求与剧本拆解，门下省负责审核，尚书省负责任务调度，户部/兵部/工部/刑部/礼部分别负责资产、镜头、生成、质检和交付说明。
- 为 AI 漫剧制片流程增加人工确认节点，避免系统从灵感直接批量生成导致跑偏；用户可以先确认故事，再审核人物、道具、场景等资产拆解结果。
- 优化镜头提示词生成逻辑，将原本模板化的“分镜/运镜描述”升级为包含参考资产、动作链、表演意图、摄影、灯光和视频生成提示词的导演式提示词结构。
- 建立模型配置与连通性测试页面，让不同办公室和部门可以独立配置 DeepSeek、千问、豆包 Seedream 等模型，降低跨办公室模型调用冲突风险。
- 完成前后端核心功能开发，使用 FastAPI、原生 HTML/CSS/JavaScript、SQLite、本地文件存储和 Word 文档生成能力，实现本地运行、历史记录、产物下载和配置隔离。

项目成果：

- 已形成可本地运行的多 Agent 产品原型，支持办公室大厅、研究办公室、AI 漫剧制片办公室、模型配置测试、历史记录和 Word 制片画布导出。
- AI 漫剧制片办公室可以从一个灵感或完整剧本出发，产出结构化制片包，包括故事稿、人物设定、道具设定、场景广角/俯视/机位参考、导演提示词、视频提示词和交付画布。
- 针对复杂生成链路补充 40+ 条单元与接口测试，覆盖办公室隔离、模型配置隔离、资产审核、历史下载、镜头提示词和 Word 画布生成等关键路径。
- 项目已整理为公开 GitHub 仓库，并在个人网站中作为核心作品展示，适合作为多 Agent 产品设计、AI 工作流编排和产品工程化能力的综合案例。
