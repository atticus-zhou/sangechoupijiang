# AI 漫剧办公室生产级加固设计

## 目标

让 AI 漫剧办公室在真实用户流程中做到三件事：密钥不泄露、状态不撒谎、所有资产继承同一视觉时代与画风。系统必须在质量不合格时停下来，而不是继续显示“100 分、已完成”。

## 范围与优先级

### 第一阶段：生产安全与可信状态

1. `/api/config/models` 不再返回完整 API Key，只返回 `has_api_key` 和脱敏占位信息。
2. 模型配置页面不依赖后端回传原密钥；留空表示保留，显式填写才替换。
3. 图片输出目录调整为 `output/workspaces/<workspace_id>/generated/<task_id>/`，不同任务不得共享文件名。
4. 每张图片开始、成功、失败、质检和重试都写入任务事件，前端展示 `已完成/总数`、当前资产和失败数。
5. 图片质量结果进入最终质量门：任何 `needs_review`、`fail`、0 分或未执行视觉质检，均不得标记刑部完成，也不得显示验收 100 分。
6. 质检报告必须区分“未发现问题”和“质检未执行/质检失败”，禁止用前者掩盖后者。

### 第二阶段：视觉风格圣经与古风锁定

1. 从题材、视觉风格和确认剧本生成结构化 `style_bible`，至少包含 `style_id`、时代、媒介、服装、发型、材质、建筑、道具、色彩、灯光和禁用元素。
2. 人物、道具、场景、镜头都写入同一个 `style_id`，并在最终生图提示词硬注入风格锚点。
3. 古风/仙侠项目默认禁用现代服装、现代发型、塑料包装、玻璃药瓶、现代印刷标签、现代建筑、汽车、电灯和现代家具；只有剧本明确要求穿越或现代元素时才允许例外。
4. 人物基础资产保持白色或近白色干净背景，道具同样保持干净背景；场景保持真实空间，不做白底。
5. 刑部视觉质检新增时代、媒介、人物画风、道具材质和场景建筑一致性检查。发现现代元素或画风漂移时，给出具体重生成提示词。
6. 资产审核包显示每项资产继承的风格 ID、时代和禁用元素，让用户在生图前就能发现风格错误。

### 第三阶段：提示词与故事状态

1. 提示词增强 JSON 使用更小的分批请求，分别处理人物、道具、场景和镜头，降低一次性返回无效 JSON 的概率。
2. 解析失败时保存原始错误类型并有限重试；仍失败则明确显示“规则模板降级”，不得伪装成 LLM 增强成功。
3. 完整故事模式从正文识别结尾，不再要求用户重复确认已存在的结尾。
4. `ready_to_produce`、`stage`、`missing` 必须一致；`missing=[]` 且剧本验证通过时进入可确认状态。
5. 用户选择的集数必须生成对应数量的分集大纲，不足时阻塞生产并要求补齐。

## 数据流

1. 内阁锁定故事和用户选择的视觉方向。
2. 中书省生成生产任务书和结构化风格圣经。
3. 门下省检查故事资产与风格规则是否完整。
4. 用户审核人物、道具、场景及其风格继承关系。
5. 尚书省派发，户部登记带 `style_id` 的资产身份证。
6. 兵部生成绑定资产身份证和风格身份证的镜头提示词。
7. 工部按任务隔离目录逐张生成，并持续写进度事件。
8. 刑部逐张质检时代与画风；不通过则重试或转人工审核。
9. 只有质量门通过后，礼部才生成最终 Word 并标记可交付。

## 状态与错误处理

- `prompt_fallback`：提示词增强失败但允许用户审核规则模板。
- `image_generating`：必须携带总数、当前序号和当前资产。
- `quality_review_required`：至少一张图未通过，禁止最终交付状态。
- `ready_for_handoff`：故事、资产、提示词、图片和质检全部满足要求。
- 外部模型错误需要记录部门、模型、资产 ID、尝试次数和脱敏错误；禁止记录 API Key。

## 验收标准

1. 配置读取接口响应中不存在完整 API Key。
2. 两个任务在同一工作区生成同名资产时，文件路径不同且互不覆盖。
3. 每张图片至少产生开始与结束事件，前端可展示批次进度。
4. 三张 `needs_review` 加一张 `pass` 的批次不能获得 100 分，也不能显示刑部完成。
5. 古风仙侠项目的所有人物、道具、场景提示词包含同一 `style_id` 和古风锚点，并包含现代元素禁用规则。
6. 现代药瓶、现代服装或现代建筑出现在古风图片时，刑部必须判定不通过。
7. 3 集项目必须有 3 集大纲；完整故事已有结尾时可直接确认。
8. 所有新增行为均有先失败后通过的自动化回归测试。

## 非目标

- 本轮不重做办公室整体 UI。
- 本轮不更换用户现有模型供应商。
- 本轮不重构整个三省六部引擎，只收紧 AI 漫剧办公室的生产边界。
